# Boot Scootin' — play

A neon honky-tonk line-dance game. Climb the ladder to 100x and tip your hat before the
floor gives way. Maths by Fortune Engine (96% RTP).

**Play:** https://lettuce-create.github.io/boot-scootin-play/

This repo holds only the built game. The source is in Lettuce-Create/Games (private);
publish a new build with `boot-scootin/tools/publish_play.sh` there.
